持ち物リスト

購入リストでチェックしたものは、自動でここに入ります。「少なめ」の印や購入リストからの移動は、このブラウザに保存されます。

＋ 持ち物を直接追加する
  1. 写真がある場合は、先に GitHub の「Add file → Upload files」で images/tools/ に写真をアップロードします。
  2. 下の文章をコピーします。
  3. data/items.json を GitHub で開く（鉛筆アイコンで編集）
  4. "items": [ の行の直後に貼り付けて、「Commit changes」を押します。
  5. 一覧が空のときは、貼り付けた文章の末尾のカンマ（,）を消してください。

購入リストからの移動は、このブラウザだけに保存されます。別の端末にも反映したいときは、下のボタンで文章をコピーし、data/items.json に貼り付けてください。
